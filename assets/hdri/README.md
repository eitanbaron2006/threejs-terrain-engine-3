# Optional offline HDRI files

The Sky & Sun Studio can load any `.hdr` file directly from the UI. Built-in presets first try these local files, then their Poly Haven remote fallback, and finally the procedural sky.

Suggested local names:

- `kloofendal_48d_partly_cloudy_puresky_2k.hdr`
- `sunflowers_puresky_2k.hdr`
- `overcast_soil_puresky_2k.hdr`
- `kloppenheim_06_puresky_2k.hdr`

All four corresponding Poly Haven assets are CC0. The HDR files are intentionally not bundled because of their size.
