# Terrain Materials

The manual KTX2 manifest workflow is no longer part of the user interface.

Use the **Terrain Material Pack** panel:

- choose a built-in pack, or
- import a ZIP containing `terrain-material-pack.json` and four PBR maps for each of four layers.

The application creates the WebGL2 texture arrays, mipmaps and splat distribution automatically. See `../material-packs/README.md`.
